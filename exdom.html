DOM (DOCUMENT OBJECT MODEL)

O DOM (Document Object Model) é o Modelo de Objetos do Documento. É uma representação estruturada de uma página HTML que permite ao JavaScript acessar, modificar, adicionar e remover elementos de uma página Web. Em termos simples: o DOM é a ponte entre o HTML e o JavaScript. 1. Como funciona o DOM? Quando você cria uma página HTML e abre no navegador, ele interpreta o código e constrói uma estrutura em forma de árvore, chamada Árvore DOM.

Essa árvore representa a hierarquia dos elementos HTML: - document: representa o documento. - html: elemento principal. - head: contém configurações e metadados. - body: contém o conteúdo visível. - h1, p, button: elementos dentro do body.
